# FUTANI GESTION

Système interne de gestion, de comptabilité (SYSCOHADA révisé), de pilotage et d'administration de **FUTANI GROUP** (Sénégal). Ce n'est pas un SaaS commercialisable.

Une seule entité juridique, quatre branches analytiques : FG (administration), FS (Shop), FT (Tech), FD (Digital).

## État actuel

**Phase 0 — cadrage industriel et documentation.** Aucun code métier. Voir `docs/00-CADRAGE/REGISTRE-DECISIONS.md` pour les décisions et leur statut.

## Organisation

- `docs/` : référentiel documentaire (cadrage, fonctionnel, comptabilité, fiscalité/paie, architecture, données, sécurité, qualité, roadmap, validation)
- `ADR/` : décisions d'architecture
- `apps/`, `packages/`, `infrastructure/`, `tests/` : réservés aux phases suivantes
- `PROMPT-MAITRE-FUTANI-GESTION.md` : cadre de travail du projet

## Principe

Aucune règle juridique, fiscale ou sociale n'est tenue pour certaine tant qu'elle n'est pas vérifiée auprès de sources officielles ou d'un professionnel compétent.
